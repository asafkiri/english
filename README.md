# אנגלית טכנית לחשמל

אפליקציית ווב (PWA) ללימוד האנגלית של לימודי הנדסאי חשמל: לקרוא מפרטי יצרן, לוחיות נתונים, טבלאות והוראות. הממשק בעברית ומימין לשמאל; המונחים, היחידות והדוגמאות באנגלית משמאל לימין.

## מה יש כאן

- `index.html` — כל האפליקציה בקובץ אחד, בלי שלב בנייה. המאגר מוטמע בתוכו בין הסימונים `CONTENT:BEGIN` ו־`CONTENT:END`.
- `content/electrical_english_vocabulary.json` — מקור האמת של התוכן: 173 מונחים ב־9 נושאים, 5 תרגילי הבנה ו־21 מקורות לעיון.
- `tools/embed-content.mjs` — מייצר מחדש את בלוק התוכן ב־`index.html` מתוך קובץ ה־JSON.
- `tests/app.test.mjs` — בדיקות שמריצות את הסקריפט של האפליקציה ב־Node עם DOM מדומה.
- `service-worker.js`, `manifest.webmanifest`, אייקונים — עטיפת ה־PWA (עבודה לא־מקוונת והתקנה למסך הבית).

## איך האפליקציה מלמדת

- **מפגש**: קודם חזרה על מונחים שכבר נלמדו (עד 12 במפגש), ואז עד חמישה מונחים חדשים; אפשר לבחור פחות, או אפס כדי לחזור בלבד. שלושת המפגשים הראשונים קבועים לפי מסמך התכנון; אחריהם הסדר המומלץ הוא לפי רמה ונושא, ואפשר לבחור נושא ידנית.
- **כרטיס מונח**: המונח באנגלית, תרגום מקצועי, הסבר קצר, משפט לדוגמה ותרגומו, ועוד יחידה, קיצורים ומונחים דומים כשיש. הקראה בקול הדפדפן, רק כשהוא מציע כזו.
- **תרגול**: התאמת אנגלית לעברית, עברית לאנגלית, זיהוי המונח החסר במשפט, בחירת השדה הנכון בתבנית מפרט, והבחנה בין מונחים דומים לפי ההסבר. לכל שאלה ארבע אפשרויות ותשובה נכונה אחת; אפשרויות שנקראות כאותה תשובה (קיצור, שם נרדף, תרגום זהה) לעולם לא מופיעות יחד.
- **אחרי טעות**: הסבר בעברית על מה שנבחר ועל התשובה, דוגמה, והמונח חוזר בהמשך המפגש בצורה אחרת. אפשר לסמן ״הבנתי את האנגלית, לא את המושג בחשמל״; הסימון נשמר בנפרד מהטעויות בשפה.
- **חזרות**: לכל מונח ארבעה מצבים — חדש, בתרגול, לחזרה, שליטה מבוססת. מרווחי ברירת המחדל: יום, שלושה ימים, שבוע, שבועיים, חודש. תשובה נכונה מקדמת רק כשהמונח באמת היה לחזרה; טעות מורידה דרגה ומחזירה אותו למחר. שליטה מבוססת נרשמת רק אחרי כמה חזרות מרווחות מוצלחות.
- **שמירה**: ההתקדמות נשמרת ב־`localStorage` של המכשיר תחת מפתח אחד. מפתחות האפליקציה הקודמת שהייתה בכתובת הזו נמחקים בכל פתיחה ואינם נטענים.

## עדכון תוכן

עורכים את `content/electrical_english_vocabulary.json` ומריצים:

```
node tools/embed-content.mjs
```

הבדיקות נכשלות אם `index.html` לא עודכן אחרי שינוי ב־JSON.

## בדיקות

```
node --test tests/app.test.mjs
```

## הגבלות תוכן

התרגומים, ההסברים ומשפטי הדוגמה הם ניסוח לימודי; המקורות צורפו לעיון במינוח ולא אומתו מחדש. תרגילים עם נתונים מדומים מסומנים ככאלה, ולא מומצאים נתוני מכשיר או דרישות תקן.
